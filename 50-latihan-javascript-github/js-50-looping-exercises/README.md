# 50 Latihan JavaScript

Kumpulan solusi JavaScript untuk 50 soal latihan looping, string, deret, bilangan, tahun kabisat, dan animasi.

## Cara menjalankan

Pastikan Node.js sudah terpasang.

```bash
node 01_reverse_sentence.js
```

Untuk soal animasi (34–41), buka file HTML terkait di browser:

- `34_animasi_horizontal_maju_mundur.html`
- `35_animasi_horizontal_bolak_balik.html`
- `36_animasi_bawah_maju_mundur.html`
- `37_animasi_bawah_bolak_balik.html`
- `38_animasi_vertikal_kiri_turun_naik.html`
- `39_animasi_vertikal_kiri_bolak_balik.html`
- `40_animasi_vertikal_kanan_turun_naik.html`
- `41_animasi_vertikal_kanan_bolak_balik.html`

## Struktur

- Soal 01–33: program Node.js sederhana.
- Soal 34–41: animasi browser menggunakan HTML + JavaScript.
- Soal 42–50: program Node.js dengan input/looping.

Setiap file diberi komentar singkat agar mudah dipelajari dan dikembangkan.
