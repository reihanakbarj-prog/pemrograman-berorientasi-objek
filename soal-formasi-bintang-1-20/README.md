# Soal Formasi Bintang 1–20

20 latihan formasi karakter berdasarkan gambar soal.

## Menjalankan

Pastikan Node.js sudah terpasang, lalu jalankan contoh:

```bash
node "Soal 1.js"
```

Semua program menggunakan `for` dan operasi string JavaScript agar pola dapat dihasilkan secara programatis.

## Catatan

Spasi pada output penting untuk membentuk pola. Soal 4 pada gambar menggunakan bentuk dua sisi yang bertemu pada baris terakhir.
