# 50 Latihan JavaScript

Kumpulan solusi JavaScript untuk 50 soal latihan.

## Daftar file

Semua latihan diberi nama sederhana:

- `Soal 1.js` sampai `Soal 33.js`
- `Soal 34.html` sampai `Soal 41.html` untuk animasi
- `Soal 42.js` sampai `Soal 50.js`

## Menjalankan file JavaScript

Dengan Node.js:

```bash
node "Soal 1.js"
```

Nama file memakai spasi, jadi gunakan tanda kutip saat menjalankannya di terminal.

## Soal 34–41

Buka file HTML berikut langsung di browser:

```text
Soal 34.html
Soal 35.html
...
Soal 41.html
```
